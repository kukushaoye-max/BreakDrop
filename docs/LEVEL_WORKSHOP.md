# 关卡工作台：固定支点与铰链跷跷板

Unity 2022.3.13f1c1，菜单 `Tools > Break & Drop > Level Workshop`。

## 使用流程

1. 从七个模板新建，或导入现有关卡 JSON。左侧是独立草稿库；不会修改正式关卡。
2. 在中央画布选中、拖动积木（0.25 单位吸附），Ctrl 多选。积木下拉框提供全部 11 款素材预设（A/B/I：2×1，C/E/K/L：1×1，G：3×1，R：5×1，D：L3 3×3，J：L2 2×3），附素材预览与 0/90/180/270° 旋转选项。添加后尺寸、形状、素材和质量自动匹配，右侧仍可自定义。机关工具栏支持固定支点、跷跷板，复制和删除；右侧配置目标、终点、边界、积木和铰链参数。支持 Unity Undo。
3. 点击“试玩”，点击积木拆除；可暂停、回退、重开，成功后保存本次路线。预览使用隔离物理场景，不消耗游戏体力。
4. 点击“验证 / 搜索参考路线”。先检查结构，再检查已有路线；失败时进行预算内搜索（宽度 48、深度 12、最多约 2000 次路线评估）。找到路线后逐步尝试删除冗余步骤，再重建十次验证。贪心删步不保证全局最短。
5. 验证报告记录逐步目标落点与承托 ID；“显示参考落点轨迹”显示稳定落点连线，不代表逐帧运动路径。可单独导出报告。难度只是步数、承托变化和机关数的启发式建议。
6. 勾选“人工精选加入关卡集”，用 ordinal 排序，再“导出精选集”。输出目录为 `LevelWorkshopReleases`，含新关卡 JSON、校验清单和报告。
7. 试玩确认后，使用“发布候选包”选中导出目录并确认追加。发布前重新核对草稿、代码、物理配置和正式目录；只新增编号，不覆盖原关卡。旧 JSON 备份在包内，写入失败会撤回本次新增文件。

## 批量与模板

默认一次 100 个候选，固定种子使同版本输入可重现。点击“暂停任务”释放仿真，再“续跑”从 `Library/LevelWorkshop/batch.json` 恢复；当前候选会重新验证。新开批次替换旧断点。Library 被清理后断点丢失，已存草稿保留。

选中 template 草稿时使用它批量生成，否则使用顶部预设。`lockedBlocks` 保存不参与变化的积木 ID。`ranges` 支持积木 x/y/width/height/mass/rotation 和铰链 anchorX/anchorY/lowerAngle/upperAngle；blockId 为 0 时只支持目标 x/y。min/max/step 指定离散范围。没有 ranges 时使用 positionVariation 对未锁定积木横向扰动。预设批量采用质量变化。

完全相同的数据会去重，100 个候选不等于 100 个合格关卡；结构或镜像相似度超过 60% 只作提示。草稿和代码修改后旧验证失效，必须重新验证。未找到解仅表示预算内未找到，不是无解证明。

## 机关与扩展

固定支点使用不可拆静态积木。跷跷板使用不可拆动态矩形、世界固定锚点的 HingeJoint2D、角度限制，无电机；配重块可拆。右侧 mechanisms 编辑锚点与角度，画布显示支点和角度弧。

关卡 schemaVersion 为 2，旧 JSON 仍兼容。MechanismRegistry 注册构造器；后续移动平台、弹簧可通过 ILevelMechanismState 接入 Tick、快照、还原与稳定判断。当前不实现这两种机关，未知类型会明确拒绝。

## 验证与边界

自动验收入口：`BreakDrop.Editor.WorkshopAcceptance.Run`。报告：`docs/validation/level-workshop/acceptance.json`。覆盖原 20 关各十次、新机关六个样例各十次、七种预设路线、初始穿插拒绝、取消释放物理场景、机关参数、重开与正式文件保留。

自动回归属于 Editor 中独立物理仿真，不替代真实 Play 模式、窗口交互和手机触屏验收。完整 100 候选批次的耗时/续跑压力、发布失败注入、跨平台物理结果尚需专项验收。当前难度建议不包含完整顺序敏感度评分；轨迹视图没有逐帧回放。不要仅凭“已验证”直接作为上线认证。
