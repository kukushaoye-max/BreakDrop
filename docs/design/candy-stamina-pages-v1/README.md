# 首页、选关、游戏页体力入口

仅修改三张既有设计稿，补充统一爱心体力入口；原稿保留。本轮使用内置 image_gen 编辑，提示词见 prompts.md。未修改 Unity 代码。

- 首页、选关页：左上体力入口，与右侧设置/关闭按钮分开。
- 游戏页：计时器左侧，不遮挡计时、角色与积木。
- 6/10 是展示数值，不表示实时数据。整条或加号点击后进入体力详情/补给弹窗；体力非零时不能标题写成“体力不足”，应使用“体力补给”。
- 局内打开弹窗暂停计时与物理，关闭后恢复；不扣体力、不自动播放广告。
- 继续遵循免费等待恢复、主动观看广告补充、无充值收费入口的方案。

本轮仅新增体力入口，没有重新设计原有道具栏或改动其他弹窗背景版本。
