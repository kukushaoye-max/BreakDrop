## 交互与复用说明

- 数值为方案示例。所有奖励均免费，广告奖励需用户主动选择；无充值、货币或付费入口。
- 体力上限 10，每 10 分钟恢复 1 点；开局及重开消耗 1 点。广告体力 +3，每日最多 3 次。
- 三种道具广告每次 +1、各每日最多 3 次；每日激励合计最多 10 次，每局最多 2 次，全局冷却 60 秒。图中 45 秒为冷却中的示例。
- 每日免费补给为三种道具各 1 个，无需广告，北京时间零点刷新。
- 灵感糖使用上限每局 3 次；回退糖每局 3 次、不返还时间；时间糖每局 2 次、每次 +30 秒、时间归零后不能使用。
- 道具领取后存入库存，不自动使用。仅到账成功显示成功弹窗；确认中不允许重复观看以免重复发奖。
- 广告加载弹窗仅在用户点击领取后出现；取消/X 终止本次加载，不自动重新播放。游戏中打开此弹窗暂停物理与倒计时。
- 没有广告或未完成观看不发奖励、不消耗领取次数；失败重试等待 15 秒。
- 重开确认仅用于进行中的对局；关闭或“继续游戏”均不扣体力。确认并成功启动新局后才扣除。
- 所有关闭按钮均可退出当前弹窗；奖励确认中关闭不取消后台对账。

## 共用模板状态（文字规格，未另出图片）

- 道具不足：04 模板可替换为“回退糖不足／撤销一步，不返还时间”或“时间糖不足／剩余时间增加30秒”，对应粉色回转箭头与蓝色沙漏。
- 每日补给已领：03 主按钮置灰“今日已领取”，次日零点恢复。
- 单项达到上限：06 替换为“今日体力奖励已领取 3/3次”或对应道具文案；每局达到上限则显示“本局激励已领取 2/2次”，不能写成次日重置。
- 体力为 8/9：01 按实际可领取值显示“体力＋2／＋1”，明确补至上限；观看中发生自然恢复导致溢出的已获奖励保留待领取。
- 奖励成功：12 可替换为实际体力或道具奖励，不显示自动使用或奖励翻倍。
- 没有撤销记录、已达到本局使用上限、计时结束：原有道具入口禁用并显示对应原因，不弹广告领取页。
