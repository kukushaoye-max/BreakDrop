## 材料使用边界

截图中的要求：至少 3 张 JPG/JPEG/PNG，每张 60KB–5MB，需使用微信游戏截图且游戏名一致。本包是设计稿，不能表述为真实微信游戏截图。正式提交前请按上述三个场景补充实机截图。图片无水印，文件名及本说明区分设计稿身份。

## 可参考的玩法描述（139 字符，含标点；不少于50且少于800）

玩家通过点击拆除糖果积木，改变积木塔的支撑关系。失去支撑的积木与星星六边形会在重力作用下跌落、旋转并碰撞，待结构稳定后再继续操作。玩家需在倒计时结束前，让六边形安全落稳在底部平台，无需清空全部积木，也无需匹配相同颜色。游戏免费游玩，无充值和收费项目；广告奖励由玩家自主选择观看。
