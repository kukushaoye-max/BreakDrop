## V0.1 物理原型（当前）

- [x] 建立 Unity/Codex 项目结构
- [x] 数据化加载关卡
- [x] 点击拆块与碎裂反馈
- [x] 目标、终点、边界和三星进度
- [x] 游戏状态机
- [x] Retry / Undo / Hint
- [x] 20 个差异化内部验证关卡（1–5 关 10 块、6–15 关 18 块、16–20 关 21 块）

## V0.2 关卡生产

- 可视化关卡编辑器
- 一键保存 JSON
- 最佳步骤与 Hint 顺序录入
- 基础可解性检查
- 30 个关卡与难度波形

退出条件：策划无需改代码即可创建、测试和发布关卡。

## V0.3 体验与数据

- 正式 UI 与安全区适配
- 音效、震动、相机反馈、成功/失败演出
- 事件埋点接口
- 每关成功率、重试率、Hint 率和退出率看板数据
- 微信小游戏性能与包体检查

退出条件：首轮外部小规模测试可收集完整行为数据。

## V0.4 商业化实验

- 广告抽象层
- Undo / Hint 激励广告
- 结算插屏频率实验
- 去广告预留，但不在验证前强行引入货币

退出条件：留存与广告体验的权衡有真实数据，不以展示量单独驱动决策。

## V1.0 内容扩展

- Fixed、Spike、Glass、Spring、Moving Platform 的渐进教学
- 150–200 关首发内容
- 世界主题与目标皮肤
- 每日挑战/排行榜仅在核心留存达标后评估
